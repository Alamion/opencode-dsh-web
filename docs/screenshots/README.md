# Screenshots

Real screenshots for the Marketplace listing live here.

## Shot list

1. **`opencode.png`** — the OpenCode panel in the VS Code secondary sidebar with a
   chat open (deep-linked to the last chat of the project).
2. **`dsh-coder.png`** — the DSH panel showing a Coder workspace app (for
   example DUST) running in the sidebar.
3. **`dsh-stopped.png`** — the DSH panel showing the "Workspace is stopped"
   state with the **Start workspace** button.
4. **`settings.png`** — the settings UI filtered to `dshWeb` (optional).

## How to capture

- Make the panel visible in the right sidebar and take a window screenshot.
- Keep width around 1200 px; crop to the panel (plus a little context) so the
  text stays readable.
- Commit the PNG files here and reference them from `README.md`, e.g.:

  ```markdown
  ![OpenCode panel in the VS Code sidebar](docs/screenshots/opencode.png)
  ```

Screenshots are the only reliable way to show the panels; do not replace them
with mockups presented as real UI.
